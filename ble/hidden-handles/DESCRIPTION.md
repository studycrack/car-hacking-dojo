Every enumeration so far asked the peripheral to describe itself and took the
answer at face value. That answer is generated by firmware. A Read By Type
response is a list the device chose to send, and it is free to leave things
off.

Leaving an attribute out of a discovery response does not remove it from the
attribute table. **The handle still works.** Nothing in ATT consults the
discovery list when a Read Request arrives; it looks up a handle and serves it.

So walk the handles: `0x0001` upward, one at a time, reading each and noting
what comes back. `Invalid handle` means nothing is there. Anything else means
something is.

Handles are small integers and there are not many. Write the loop.
