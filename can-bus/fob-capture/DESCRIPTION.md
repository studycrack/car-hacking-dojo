# 한 번만 지나가는 전송 붙잡기

*  CAN frame은 쌓여서 기다리지 않습니다. 전선에 잠깐 실렸다 사라집니다.
*  그때 듣고 있던 쪽만 들었습니다. 나머지에게는 일어나지 않은 일입니다.

*  그 전송 안에 플래그가 ascii로 들어 있습니다.
